Set it up

Pick your way in

✅ Nothing to sign up for💳 Claude Pro or Max📡 Fetches live when you ask
1
1 min

Get your Garmin key

  1. Open Garmin Connect → Settings → Personal API Key and sign in.
  2. Tap Create. Pick how long it lasts (30 days is safest, 1 year is least hassle).
  3. Copy the key. Garmin shows it only once.
2
30 sec

Make your skill

🔒
Your key never leaves this phone. This page has a security rule that blocks it from sending anything online; it builds the file right here. Try it: switch on airplane mode first. It still works.

You get my-garmin-data.zip. Keep it private: it contains your key. Nothing is saved on this page.

3
1 min

Add it to Claude (once, at claude.ai in a browser)

  1. Settings → Capabilities: turn on Code execution and file creation.
  2. Just below it, turn on network access (called Allow network egress, Network access or Domain allowlist), choose specific domains, and add only:
    personal.connectapi.garmin.com
    Don't pick "All domains". With only Garmin allowed, Claude itself blocks the skill from sending your data anywhere else.
  3. Skills → Upload skill → choose my-garmin-data.zip.
4

Ask away 🎉

In the Claude app or on the web: "Am I recovered enough to run hard today?"

Deploy your own copy

☁️ Deploy to Cloudflare
  1. Sign in to Cloudflare and GitHub (both free; Cloudflare keeps a copy of the code in your GitHub).
  2. When it asks for OWNER_PASSWORD, replace the example with your own: 12+ characters, a short sentence is great.
  3. Tap Deploy. You get your own link, ending in .workers.dev
3
1 min

Connect Garmin

Open your new link, log in with your password, paste your Garmin key. You'll see 🎉 Connected, and your past year starts loading in the background.

4
2 min

Add it to Claude

  1. At claude.ai (browser): Settings → Connectors → Add custom connector.
  2. Name it Garmin, paste the link your page shows, tap Connect, type your password, Allow.
  3. In any chat on your phone: ＋ → Connectors → Garmin, and ask.

ChatGPT: the same link works as a developer-mode connector (paid plans, web, beta).

Why you can trust it

Private by design, not by promise

✈️
Works in airplane mode

This page can't send anything. Your key is packed into the file on your own phone.

🧱
Locked to Garmin

You allow only Garmin's address in Claude, so the code physically can't send data elsewhere.

👀
Open source

One short Python file. Or drop the zip into Claude and ask it what the code does.

📖
Read-only

Garmin's Personal API can't change your account or send anything to your watch.
