Ask Claude about your Garmin data

Your runs, sleep, HRV, Body Battery and weight, answered by Claude on your phone. Free, private, about 3 minutes. Needs a paid Claude plan (Pro or Max).

Option 1: the Claude Skill

🔒 Your key never leaves this phone

This page has no server and a security rule that blocks it from sending anything over the internet. It builds your skill file right here. Try it: turn on airplane mode before step 2. It still works.

1Get your Garmin key

  1. Open Garmin Connect → Settings → Personal API Key and sign in.
  2. Tap Create. Pick how long it lasts (30 days is the safest; 1 year is the least hassle).
  3. Copy the key. Garmin shows it only once.

2Make your skill

You get my-garmin-data.zip. Keep it private: it contains your key. This page doesn't save anything.

3Add it to Claude (once)

Do this at claude.ai in your browser. These settings aren't in the phone app yet.

  1. Settings → Capabilities: turn on Code execution and file creation.
  2. Just below it, turn on network access (it may be called Allow network egress, Network access or Domain allowlist), choose specific domains, and add only:
    personal.connectapi.garmin.com
    Don't choose "All domains". With only Garmin allowed, the skill can't send your data anywhere else, and Claude enforces that.
  3. Settings → Capabilities → Skills: tap Upload skill and choose my-garmin-data.zip.

4Ask away, in the Claude app or on the web

  • "Am I recovered enough to run hard today?"
  • "How did my sleep this week compare to last week?"
  • "Look at my last 4 weeks of running and build next week's plan."
  • "Is my resting heart rate trending up?"

What it does, and what it doesn't

  • Reads your activities, sleep, HRV, stress, Body Battery, weight, HR zones and fitness age from Garmin's official Personal API
  • Runs inside your own Claude account. The code is open: one short Python file on GitHub
  • No accounts, no server, no tracking, nothing collected or sold
  • Can't change anything in Garmin or send anything to your watch (the API is read-only)

Want to check before you trust it? Upload the zip into a Claude chat first and ask: "Does this send my data anywhere except Garmin? Can it change anything?"

Changed your mind? Delete the key in Garmin Connect → Settings → Personal API Key, and remove the skill in Claude.
